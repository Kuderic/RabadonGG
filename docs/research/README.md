## Top-line findings (pre-launch / <100 MAU stage)

**Positioning**: Rabadon.GG is not another counter-picker — it is the only tool that scores every champion against the full draft in a zero-install web UI with transparent, inspectable scoring. Lead with this in every channel.

**Priority order**: Growth → Product gaps → Monetization. Nothing behind a paywall until ~1,000 MAU.

**Biggest near-term product gaps**: LCU client integration (auto-populate the draft), champion pool filter ("my pool"), and pre-rendered SEO pages per champion/role.

**Biggest near-term growth lever**: A value-first data post to r/summonerschool + champion mains subs, plus shareable result URLs with OG image cards.

**Monetization**: Add a Ko-fi link now. Launch a $3.99/month tier at ~1,000 MAU gating saved drafts and expanded pick lists. The core recommendation output must always be free (Riot policy + viral hook).
